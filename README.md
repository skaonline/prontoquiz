# ProntoQuiz Patente B — sito

Pagine pubbliche (GitHub Pages) dell'app **ProntoQuiz Patente B**: landing e informativa privacy.

- 🌐 Home: https://skaonline.github.io/prontoquiz/
- 🔒 Privacy policy: https://skaonline.github.io/prontoquiz/privacy.html

L'URL della privacy policy serve per:
- il **messaggio di consenso GDPR** su Google AdMob;
- la **scheda dell'app su Google Play**.

## File
- `index.html` — pagina iniziale (landing).
- `privacy.html` — informativa sulla privacy.
- `README.md` — questo file.

## Come pubblicare
1. Carica questi file nella **root** del repository collegato a GitHub Pages.
2. In *Settings → Pages*, imposta la sorgente sul branch corretto (es. `main`, cartella `/root`).
3. Attendi qualche minuto: le pagine saranno online agli URL sopra.
